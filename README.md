# Retail Sales Analysis using SQL

## Overview

This project analyzes the Superstore dataset using MySQL and SQL.

The main goal is to understand sales, profit, customers, products, and regional performance using SQL queries.

## Tools Used

- MySQL
- SQL
- Kaggle Superstore Dataset

## Analysis

The project answers questions such as:

- What are the total sales and profit?
- Which category has the highest sales and profit?
- Which products are most profitable?
- Which products are making losses?
- Which region has the highest sales?
- How do sales change month by month?
- How do different customer segments perform?
- Which cities have the highest sales?
- How does discount affect profit?

## Key Findings

- Technology was one of the strong performing categories in terms of profit.
- The West region had strong sales performance.
- Higher discounts were linked with lower profit in some cases.
- Some products had negative profit.
